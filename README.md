## 👨‍💻 About Me

I'm a **Software Engineer** with experience building end-to-end solutions, from user interfaces to backend systems and data workflows.

I have worked with technologies such as **Python, C#**, and modern frontend frameworks, developing applications that automate processes, integrate multiple systems, and handle data efficiently. My experience includes both frontend development—creating responsive and user-focused interfaces—and backend engineering, where I design scalable logic, APIs, and data processing solutions.

I’m particularly interested in building full-stack systems that are not only functional, but also reliable, maintainable, and performant. I enjoy working across the stack, solving complex problems, and bridging the gap between user experience and system design.

### 🎯 Core Expertise:
* 🚀 **Full-stack development** (frontend + backend)
* 🐍 **Python, C#**, and modern web technologies
* ⚙️ **Web scraping**, automation, and data processing
* 🔌 **REST APIs** and system integrations
* 🐙 **Version control** and collaborative development workflows

I’m always looking to grow as an engineer, take on new challenges, and contribute to projects that require both technical depth and practical problem-solving.
